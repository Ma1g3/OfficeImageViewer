# 安装与维护窗口

模式：Operate。沿用 Windows 原生工具窗口，安装任务以熟悉、清晰、可恢复为准，不改变图片查看器的视觉风格。

窗口 660×590，最小 580×540；系统标题栏，可调整大小，正文可滚动。Microsoft YaHei UI 14，标题24，内容左对齐，32px主留白。浅色背景便于安装说明阅读；主要按钮使用 Windows 蓝 #005FB8，错误文本 #A02323。沿用键盘焦点、默认按钮和原生控件行为。

从上到下：任务标题及结果说明、图片查看操作提示、安装范围、就绪/错误/进度、可展开环境及用法、底部操作。首次安装只有一个主要动作；检测到旧版则明确显示升级；已有安装可修复或进入卸载确认界面。成功页解释下一步，失败保持窗口并提供重试，不弹终端。

界面必须覆盖安装/升级、已安装维护、卸载、运行中Office拦截、成功和错误。不会强制关闭文档。默认当前用户，已有机器级安装自动建议保持原范围；需要提升时保留明确选择。
